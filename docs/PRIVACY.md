# Gitifact privacy policy

Gitifact is a browser extension that renders HTML files from public GitHub repositories inside the
GitHub web interface.

- Gitifact does not collect, store or transmit personal data.
- The only network requests it makes are to `https://raw.githubusercontent.com/` to download the
  file being previewed and the files it references, without cookies or credentials.
- The extension stores two display preferences (preview width and height) locally in the browser.
  Nothing is sent to the extension author or any third party.
- GitHub pages are modified only to add the Preview tab and the preview frame.

Contact: open an issue at https://github.com/champierre/gitifact.
